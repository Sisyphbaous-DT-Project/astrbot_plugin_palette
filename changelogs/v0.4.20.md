# v0.4.20

## 兼容性

- 核对 AstrBot `4.28.1` 到 `4.28.2` 的全部版本差异：上游修复 SQLite 时间字段存储及平台消息历史清理时区，Dashboard 页面、目录解析器和插件接口没有变化，调色盘无需修改功能实现。
- 在 AstrBot `4.28.2` 的数据库模型中写入 `ProviderStat` 并调用调色盘七天 Token 明细汇总，读写与统计结果正常；调色盘 161 项测试及上游新增的 17 项时间字段测试通过。
- 配置页与 ChatUI 的浏览器验收沿用 AstrBot `4.28.1` 结果；本地参考仓库的 `data/dist` 仍为 `v4.28.1`，未进行 `4.28.2` 构建页面浏览器验收。桌面托管模式会拒绝版本不匹配的旧 WebUI 资源。

## 版本与文档

- 更新插件元数据、README、更新日志和主题 CSS 版本标记至 `0.4.20`。没有新增配置项，也不改变 API 或持久化数据。
