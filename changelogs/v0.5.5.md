# 0.5.5

- 毛玻璃覆盖补齐：系统设置页（含「需要重启」提示条）、自定义规则、人格设定、子代理编排、未来任务、知识库、MCP、技能页的卡片跟随「界面毛玻璃」强度，内层表格、信息列表和嵌套卡片恢复透明；设置页导航的悬停和选中底色在透明度为 `0` 时也能看出当前项。
- 去掉卡片背后的整块深色底板：插件页、管理行为、技能、子代理编排、未来任务和知识库详情页的外层容器恢复透明（毛玻璃强度大于 `0` 时生效）。
- 管理行为页「指令 / 函数工具」切换条改为 `14px` 圆角，与同页筛选框统一。
- 所有下拉选项和小菜单改为玻璃表面并统一 `14px` 圆角；毛玻璃强度为 `0` 时仍保留最低约 `0.78` 的底色和边框，避免选项文字压在页面文字上。模型选择菜单保持不变。
- 选择人格、账户、欢迎页「快速引导」里的模型配置和聊天里的工作区文件预览弹窗不再被暗色主题刷成实色，改为完全透明；人格详情、人格新建与编辑（含「预设对话」折叠面板）、未来任务的弹窗去掉淡灰底框并保持透明；其余常规弹窗样式不变。
- 272 项 unittest、语法与 Ruff 检查通过；官方 4.29.0-beta.2 Dashboard 构建包的隔离实例在桌面与手机宽度下逐页截图验收，包含有真实数据的知识库。聊天里的工作区文件预览弹窗、自定义规则页有数据时的状态、技能页 neo 模式仅做源码级核对；4.26 ~ 4.28 的实页、原生桌面、旧版本浏览器矩阵及 4.29 正式版仍未验收。
