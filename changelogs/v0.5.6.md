# 0.5.6

- 适配 AstrBot 4.29.0 正式版：逐项核对相对 beta.2 的 19 个提交，插件路由、Dashboard 注入、插件页面桥接和数据库层均无变化，设置页的保存、素材预览、大素材上传与本机缓存不受影响。
- 控制台页新增的日志「过滤器」侧栏改为透明，只保留细边框，与日志区一起透出壁纸；手机等窄屏下它浮在日志上方，改为带模糊的悬浮玻璃（毛玻璃强度为 `0` 时仍保留最低约 `0.78` 的底色），避免文字叠在一起；全屏时保持 AstrBot 原有的深色底。
- 去掉控制台页卡片背后多余的一圈界面底色：此前界面底色大于 `0` 时，卡片左右和下方会露出一圈深色边框并截断壁纸图案；界面底色默认为 `0`，默认设置下本来不可见。
- 285 项 unittest、语法与 Ruff 检查通过；官方 4.29.0 Dashboard 构建包的隔离实例在桌面与手机宽度、毛玻璃强度 `14` 与 `0` 下验收了过滤器侧栏与页面外层底色，其余新界面仅做源码级核对；4.26 ~ 4.28 的实页、原生桌面和旧版本浏览器矩阵仍未验收。
