# v0.4.15

## 修复

- 修复窄屏（手机、竖屏平板、窄窗口）下打开侧栏时，透明浮层侧栏与主内容文字重叠穿透的问题：Vuetify 在窄屏将未设置 `permanent` 的侧栏切为 temporary 浮层，布局占位为 0，默认全透明的侧栏会直接盖在全宽正文上。
- 修复规则作用于所有 temporary 侧栏，玻璃底色和滤镜不绑定 `v-navigation-drawer--active`，侧滑拖拽打开的中间态也不会出现透明穿透；外层阴影只在 `--active` 打开态渲染，关闭态不会在屏幕左缘残留阴影；桌面 permanent 侧栏不受影响。

## 新增

- 新增独立配置 `mobile_sidebar_glass`（移动端侧栏毛玻璃强度，默认 `18`，范围 `0`–`40` px）：窄屏浮层侧栏获得实底、模糊和阴影，与界面毛玻璃 `stats_card_blur` 完全脱钩；`0` 表示显式关闭侧栏底色、模糊和阴影并恢复透明，不会被界面底色规则重新染色。
- Dashboard 主侧栏和聊天页（ChatUI）侧栏一并适配；聊天页侧栏保持 Vuetify floating 的无边框设计，用阴影完成层次分隔，不强加边框。
- 设置页新增「移动端侧栏毛玻璃」滑块和预览示意，预览侧栏随配置实时反映强弱。

## 资源

- 更换插件图标 `logo.png`，保持 AstrBot 插件规范要求的 1:1、`256x256` PNG，用于插件市场和插件列表。
- README 顶部主视觉图改用原始尺寸的 `docs/images/logo-artwork.png`（`1254x1254`），插件图标与展示图分开维护，避免为适配列表尺寸损失画面细节。

## 兼容范围

- 保持最低 AstrBot 版本 `>=4.26.0-beta1`，不涉及 Dashboard 注入逻辑变更。
- 旧配置缺少 `mobile_sidebar_glass` 字段时读取默认 `18`，下次保存自然写入，不做主动迁移。
- 原生配置入口写入的越界值在后端公开配置和运行时 CSS 双侧夹取到 `0`–`40`。

## 验证

- Python 编译检查、设置页 JavaScript 语法检查、JSON 解析检查和 Git 空白检查通过。
- 调色盘标准库回归测试全部通过，新增用例覆盖默认值、上下限夹取、`0` 值显式关闭、双前缀 `backdrop-filter`、`!important` 覆盖、与 `stats_card_blur` 的独立性和设置页静态接入。
