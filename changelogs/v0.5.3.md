# 0.5.3

- 新增大素材分块上传：完整包达到 `16MiB` 时按默认 `8MiB` 切片传输，适配 AstrBot 4.29 的 `128MiB` 单请求限制。小包保留原接口，原素材没有固定总量上限，仍受磁盘、网络和浏览器能力约束。
- 图库与 Wallpaper Engine 导入共用上传器，提供确认进度、有限重试、取消、过期清理和重启后的成功回执恢复。分块结果未知时同页重试核对原会话；成功后重新选择同文件开始新上传，删除后可重新加入。
- 成功确认读取最新图库和外观设置，重复完成不重新入库、不删除已提交素材。入库确认最多等待 `180 秒`，连续三次请求失败提前结束。
- 取消区分服务器停止与本地停止等待；已经开始入库的素材继续确认并更新图库，后续队列停止。重载等待文件工作线程结束后再清理。小包旧接口没有服务器重试去重，结果未知时应先核对图库。
- 页面离开后恢复原实例，未交付的分块结果保留原身份；缩略图预览最多等待 `15 秒`，取消或离开使旧请求失效，迟到响应不覆盖页面。
- 适配 AstrBot 4.29 的正文高度、外框装饰及深色 Chat 渐变，保留旧版本高度回退、配置页裁剪和固定按钮行为。
- 导航 SVG 图标增加可读性增强，导航当前项、折叠/设置按钮和 MCP 批选保留交互反馈，延续毛玻璃与透明主题设置。
- 236 项 unittest、30 组前端行为、语法、Ruff 与 diff 检查通过；隔离真实插件路由/multipart 验证大于 `128MiB` 视频包分块入库、SHA-256、封面、两方向图库及用户隔离。最小 Chromium 样式验证通过；真实 4.29 Dashboard、浏览器恢复、原生桌面与旧版本浏览器矩阵仍未验收。
