# v0.4.19

## 修复

- AstrBot `4.28.1` 配置页顶部工具栏在所有毛玻璃档位下随正文滚动，禁用造成黑色横条的独立背景层；正文滚动区域收在应用顶栏下方，工具栏分隔线不再横贯屏幕。
- 修复 standard 与 product 两种配置分组卡片的样式优先级，清除内层重复装饰，保留单层卡片玻璃和旧版配置页兼容规则。
- Bot 模式顶栏、桌面侧栏和正文外围只铺一层底色，去除明暗接缝；顶栏图标按钮保持一致的尺寸和交互反馈。
- ChatUI 欢迎区、输入区外壳和桌面侧栏不再重复叠色；侧栏导航和顶栏按钮默认透明，悬停、键盘聚焦、菜单展开及选中时保留反馈。输入框、消息气泡和窄屏浮层侧栏仍保留独立可读性样式。

## 验证

- 161 项 `unittest` 通过，Python 编译、设置页 JavaScript 语法和差异检查通过。
- 在隔离 AstrBot `4.28.1` 实例与真实 Chromium 中验证桌面与 390px 窄屏、深浅主题、毛玻璃 0/14/40、底色 0/0.4、两种配置卡片、滚动、固定按钮、输入与菜单、侧栏及顶栏交互；ChatUI 的消息记录由浏览器本地模拟提供，不向外部模型发送请求。
- 本次未对 `4.26/4.27` 重新进行浏览器验收；新配置页滚动规则在旧结构下空匹配。

## 升级说明

- 不增加配置项，也不改变 API、持久化数据或背景图库。更新插件并刷新 Dashboard 后，新版主题 CSS 会使用新的版本参数加载。
