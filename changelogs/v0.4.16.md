# v0.4.16

## 兼容性

- 适配 AstrBot `4.28.0-beta.1` 的 Dashboard 结构变化：配置页从标签翻页改为滚动工作区（`config-workspace`）、新增会话工作区（`conversation-workspace`）、平台页改为机器人工作台（`platform-workbench`）、统计/会话/日志/Trace 合并进 `/data` 路由；调色盘的 CSS 全部基于类选择器而非路由，路由合并无需适配。
- AstrBot 4.28 已移除 4.26.x 旧版 Dashboard 辅助函数（`get_bundled_dashboard_dist_path` 等），插件的三组兼容导入自动兜底为 4.27.x 起公开的 `resolve_dashboard_dist`，注入目标选择行为不变。
- 复核 AstrBot 4.28 的插件 Web API（`astrbot.api.web` 零变更）、`ProviderStat` 统计字段（无变化）、插件配置机制（配置迁移仅作用于核心配置，不影响插件），Token 明细面板挂载点 `.stats-page .token-grid` 与范围按钮均保持可用。

## 新增覆盖

- 会话工作区：接管 `--workspace-card` / `--workspace-surface` / `--workspace-subtle` 变量，三张主卡片（筛选、列表、预览）整体跟随透明主题并挂载玻璃模糊。
- 平台页：接管 `--platform-surface` / `--platform-border` 变量，工作台背景与分隔条跟随透明主题，工作台挂载玻璃模糊。
- 配置页新结构：粘性工具栏的通栏实色背景条改为跟随透明度的玻璃条；配置分组卡片（`config-standard-section__groups .v-card`）玻璃化；`--config-border` / `--config-divider` 变量接管；AI 配置禁用态实色表面统一。
- 「未保存更改」浮动提示（`.unsaved-changes-pill`）从原生固定 `blur(16px)` 改为跟随界面毛玻璃强度配置。
- 配置方案菜单（`.config-profile-menu`，渲染在 overlay 层）单独接管表面与边框。

## 说明

- 原生背景透明的交互组件（配置导航项、AI 配置页签、运行器选项、统计页 UMO 按钮等）不做覆盖，保留原生悬停/选中态。
- 4.26/4.27 时代的配置标签窗口裁剪等旧规则全部保留，继续兼容旧版 AstrBot。
- AstrBot 4.28 的插件设置页改为文件系统扫描发现页面：以符号链接挂载的插件会因路径安全检查返回空页面列表（设置页入口按钮消失），本地开发请改用 bind mount 方式挂载插件目录；正常安装的用户不受影响。

## 验证

- Python 编译检查、设置页 JavaScript 语法检查通过。
- 调色盘标准库回归测试全部通过（109 项），新增 `AstrBot428SurfaceTest` 覆盖变量接管、新玻璃载体的默认模糊与 0 值关闭、粘性工具栏背景条和配置方案菜单 overlay。
- 在 AstrBot `4.28.0-beta.1` 实际运行环境中验证插件加载、Dashboard 注入、插件列表设置页入口和页面渲染。
