# v0.4.10

## 优化

- 将 `stats_card_blur` 的毛玻璃效果扩展到组件管理、行为管理页面的按钮组、输入字段、警告框和数据表，并同步作用于侧栏当前选中项。
- 组件管理数据表使用独立伪元素承载玻璃效果，避免表格内容和分页选择器重复叠加模糊。
- 强度设为 `0` 时关闭新增玻璃装饰，让信息框和组件管理表面恢复透明，同时保留侧栏原有选中底色。

## 修复

- 修复配置页切换标签时新旧页面在动画期间短暂同时显示的问题：配置标签窗口恢复 `overflow: hidden` 裁剪，由最外层窗口统一裁掉位移到框外的内容。
- 保留保存、代码编辑和测试聊天三个固定按钮的定位行为，不改变配置面板的固定按钮安全约束。
- 补充配置标签窗口、组件管理玻璃和侧栏选中项回归测试，覆盖 `stats_card_blur` 为 `0`、默认值和最大值时的行为。

## 兼容性

- 不新增插件 API 或配置字段，继续支持 AstrBot `>=4.26.0-beta1`。
- 配置页裁剪规则按 AstrBot `4.26.7` 的 Vuetify `v-tabs-window` 结构编写；当前未在实际运行中的 AstrBot `4.26.8` 环境完成浏览器联调。
