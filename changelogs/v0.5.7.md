# 0.5.7

- 适配 AstrBot 4.29.3：逐项核对 4.29.1 到 4.29.3 的 29 个提交，插件路由、Dashboard 注入、数据库和设置页桥接均无变化。
- 追踪页整页放在一张跟随毛玻璃强度的玻璃卡片里；右侧详情面板改为四周留空的圆角卡片，筛选面板在桌面端透明。窄屏下浮起的详情与筛选面板改为带模糊的圆角浮层，背后的列表文字不再透出来，毛玻璃强度为 `0` 时仍有最低约 `0.78` 的底色。
- 吸顶表头去掉深色底，只靠模糊挡住滚动内容；毛玻璃强度为 `0` 时完全透明，滚动中的行会与表头文字短暂重叠。选中行恢复主色底并保留原生悬停反馈；旧版本追踪页规则继续保留。
- 控制台「安装 Pip 库」弹窗恢复原生实色卡片、输入框和弹窗阴影；控制台全屏时的「导出诊断包」弹窗使用同一修复，挂在 body 层的常规弹窗不受影响。
- 311 项 unittest（新增 26 项）、Python 语法、Ruff 与 diff 检查通过，关键规则的变异检查均能被测试抓住；官方 4.29.3 Dashboard 构建包的隔离实例在深浅色主题、桌面 / `1000px` / 手机宽度、毛玻璃 `14` 与 `0`、界面底色 `0` 与 `0.35` 下完成实页验收。4.26 ~ 4.29.1 的实页、原生桌面和旧版本浏览器矩阵未验收。
