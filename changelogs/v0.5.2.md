# 0.5.2

- 新增默认启用的 IndexedDB 本机背景缓存，原素材/封面首次使用后保存，刷新、关闭重开浏览器及重启机器后复用；已设置的旧壁纸也自动缓存，无需重新上传。
- 普通磁盘缓存预算 1GiB，淘汰较久未使用的普通素材；单个超过预算的大素材也保存，不占普通预算、不参与普通淘汰。所有存储仍受浏览器实际配额约束。
- 取消图片、视频和 SVG 原素材的插件体积上限，上传、下载、预览和 Wallpaper Engine 导入统一适配，保留格式识别及封面处理。
- 图库新增本机缓存占用和清理按钮，独立素材预览也复用缓存；清理只影响本浏览器，不删除服务器素材或中断当前播放。
- 存储受限、超额或失败时正常联网播放；配置/权限仍需服务器核验，不提供完整离线 AstrBot。
- 保留现有内存缓存预算、视频卸载回收、下载取消、背景轮换及旧配置兼容。
- 186 项 unittest、Python/JavaScript 语法、Ruff 与 diff 检查通过；真实 Chromium 19 项断言覆盖旧壁纸自动入库、刷新/浏览器重启后不重复下载、opaque 沙箱预览/清理、LRU 与大素材例外、跨实例清理防回填、存储失败回退和登录失败不复用。大素材策略使用缩小预算验证同一算法，没有实际向用户磁盘写入多份 GiB 文件；没有重启用户机器或完成真实 AstrBot 全链路验收。
