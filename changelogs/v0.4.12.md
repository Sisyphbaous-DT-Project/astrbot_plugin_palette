# v0.4.12

## 新增

- 新增定时轮换背景开关与分钟间隔配置，支持 `1`～`1440` 分钟，默认 `30` 分钟；轮换按当前视口方向图库随机选择，且不会连续重复当前图片。
- 页面隐藏时暂停轮换，恢复可见后重新等待完整间隔，不补播错过次数；图库为空或只剩当前一张图时静默跳过。
- 同一浏览器的同源 WebUI 标签页通过 Web Locks 持续领导权协调轮换，不支持时降级为 localStorage 租约；其他标签页通过 BroadcastChannel 和 storage 事件同步叠化到新壁纸。

## 优化

- Dashboard 背景 object URL 缓存改为上限 4 的保护型 LRU，只淘汰未被当前图层、叠化图层和在途请求引用的 URL，降低长时间轮换的内存占用。
- 轮换、普通刷新、方向切换和跨标签同步共用一致的配置应用与背景叠化流程；手动换图、方向变化、页面恢复和轮换完成后都会重新等待完整间隔。
- 完善并发请求、页面隐藏、领导权释放、租约续期和缓存整体回收的保护，避免重复轮换、硬切、失效请求覆盖新背景或迟到下载重新填充已清空缓存。

## 测试

- 新增轮换配置和定时随机接口测试，覆盖旧配置默认值、间隔上下界、选池优先级、排除当前图片、单图与空图库静默跳过，以及关闭轮换时不保存配置。
- 新增 Dashboard bootstrap 脚本语法与结构回归测试，并补齐设置页控件、schema 和 README 静态断言。

## 兼容性

- 复用 `POST /astrbot_plugin_palette/backgrounds/random-select`，仅新增可选请求字段 `scheduled`；未传时保持原有手动随机和刷新随机语义。
- 旧配置读取时自动使用 `background_rotation_enabled=false` 与 `background_rotation_interval_minutes=30`，无需主动迁移；最低 AstrBot 版本仍为 `>=4.26.0-beta1`。
- 已确认兼容 AstrBot `4.27.2`，继续保留 AstrBot `4.26.x` Dashboard 路径兼容逻辑。
