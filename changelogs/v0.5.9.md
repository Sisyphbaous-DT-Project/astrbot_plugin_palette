# AstrBot调色盘 0.5.9

## AstrBot Desktop 插件界面扩展

- 打包桌面版（`ASTRBOT_DESKTOP_CLIENT=1`）在任何 Dashboard 目录解析或读取之前直接返回不支持入口注入：不写入口、不复制 `data/dist`、不建备份、不动重启标记。支持插件界面扩展时提示在设置页授权；不支持界面扩展的桌面版提示需要使用支持该功能的桌面版，或改用源码、Docker。只有 `ASTRBOT_DESKTOP_MANAGED=1` 的开发态、自定义启动与普通部署仍走原注入逻辑。
- 新增 `GET /astrbot_plugin_palette/desktop-ui-extension.js`，复用普通入口注入的同一份完整启动脚本和配置、随机背景、主题样式、Token 统计四个地址，返回 `application/javascript; charset=utf-8` 与 `Cache-Control: no-store`。
- 完整 bootstrap 增加 `window.__astrbotPaletteBootstrapped` 防重入，覆盖本机缓存、动态媒体模块和主流程；同一页面第二次执行直接返回，不重复注册监听、计时器或配置请求。
- 状态接口新增 `desktop.client` 与 `desktop.ui_extensions`。设置页按能力显示授权按钮或升级提示；授权等待严格核对父窗口、响应类型和 `requestId`，60 秒超时，离开页面清理，覆盖 granted / declined / disabled / busy / invalid / error 的完整中文结果。
- README 写明 Desktop 授权、托盘停用与撤销后的刷新语义，以及旧版已改写入口导致无法启动时的手动恢复步骤。旧 `dashboard_backups` 在 Windows 上可能因文本读写换行转换与原始摘要不一致，不能依赖它恢复打包 WebUI。
- 主题 CSS 与 `THEME_CACHE_VERSION` 保持不变，不新增配置 schema 字段。
